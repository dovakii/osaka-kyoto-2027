- 原稿完整備份：`original.html`。
- 完整保留 2027/11/20–11/26 每日時間表、注意事項、住宿交通、預算及 12 項行前清單。

## 維護

`tools/build.py` 由原稿擷取內容並產生首頁，需保留 `original.html` 與圖片紀錄。執行後會覆寫 `index.html`。CSS 與互動程式分別在 `assets/style.css`、`assets/app.js`。

`tools/fetch_images.py` 是圖片取得與授權查核工具，不是瀏覽網站必要條件；可重用已下載檔案，無須每次執行。`tools/audit.py` 檢查七天時程保留、所有內部錨點、本地檔案、Maps 查詢格式與官方網站 HTTP 回應，輸出 `verification.json`。

2027 年機票、飯店、營業日、票價、USJ 快速通關及嵯峨野班次均須以預訂當時官方公告為準。網站外連需要網路；本地圖片與行程可離線閱讀。
